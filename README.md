# Bayberry Hills Holdings Website

Static website source. The website files are in `dist/`; there is no build step.

## Local preview

Run `python -m http.server 4173 --directory dist` from the repository root, then open http://localhost:4173.

## Current form behavior

The cash-offer form validates entries and displays contact options. It does not send or store inquiries yet.

## Assets

Photography credits, geographic-data attribution, and third-party licenses are included alongside the relevant assets in `dist/`. The renovation gallery contains illustrative concepts, not verified completed projects.

This repository starts with a clean snapshot of the current website.
